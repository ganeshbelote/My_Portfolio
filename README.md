# 🌟 Ganesh Belote - Royal Theme Portfolio

A **royal-themed**, **single-page** personal portfolio website showcasing my work, achievements, and ways to connect with me.  
Built with **HTML**, **CSS**, and **JavaScript** for the frontend, and **Node.js** to serve all files as static assets.  
Hosted on **Render** for smooth performance and accessibility.

## 🚀 Features

- **Single Page & Fully Responsive**  
  Optimized for all devices: desktop, tablet, and mobile.

- **Royal Theme**  
  Minimal yet elegant color scheme and design, with a modern royal touch.

- **Smooth Animations**  
  Subtle hover effects and button animations for a delightful experience.

- **Sections Included**
  - **Hero Section** – Quick introduction and call-to-action.
  - **Certificates** – My professional achievements.
  - **Projects** – Portfolio of my completed work.
  - **Social Media Links** – Connect with me across platforms.
  - **Email Feature** – Contact form powered by **Nodemailer**.
  - **Download Resume Button** – Instantly download my latest resume.

- **Email Integration**  
  Uses **Nodemailer** for sending emails directly from the contact form.

- **Static File Hosting**  
  Node.js server hosts all static assets.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js (Express.js)
- **Email Service:** Nodemailer
- **Hosting:** Render

## 📂 Project Structure

```plaintext
.
├── public/              # Static files (HTML, CSS, JS, images)
├── server.js            # Node.js server
├── package.json         # Dependencies & scripts
└── README.md            # Project documentation
```

📧 Contact Form Setup
Create a .env file in the root directory:

```
EMAIL=your_email@example.com
PASS=your_email_password
```
Update server.js Nodemailer config to use your .env variables.
